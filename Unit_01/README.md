# Unidad 01 - Evaluación Integral de la Unidad I

## Asignatura

**INF-8240 Visualización de Datos I**

## Actividad

**Práctica 1. Evaluación Integral de la Unidad I**

## Descripción

Esta práctica tiene como objetivo aplicar los conceptos fundamentales de visualización de datos, estadística descriptiva, interpretación de gráficos y comunicación de resultados mediante el análisis de un caso de estudio empresarial.

El estudiante asume el rol de analista de datos para evaluar el desempeño de una empresa ficticia de comercio electrónico denominada **ComercioDigital RD**, utilizando información de ventas, reclamaciones y canales comerciales.

## Objetivos de Aprendizaje

- Identificar y clasificar variables de análisis.
- Diferenciar entre dato, información, conocimiento y decisión.
- Aplicar medidas de estadística descriptiva.
- Construir visualizaciones adecuadas para distintos tipos de información.
- Interpretar resultados basados en evidencia.
- Comunicar hallazgos mediante storytelling con datos.
- Formular recomendaciones considerando las limitaciones de los datos disponibles.

## Herramientas Utilizadas

- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab

## Contenido del Notebook

La práctica incluye las siguientes actividades:

1. Comprensión y análisis de datos.
2. Clasificación de variables.
3. Dato, información, conocimiento y decisión.
4. Beneficios de la visualización de datos.
5. Estadística descriptiva.
6. Interpretación de medidas de tendencia central.
7. Construcción de gráficos.
8. Interpretación de visualizaciones.
9. Evaluación crítica de afirmaciones.
10. Storytelling con datos.
11. Reflexión sobre comunicación y visualización en Ciencia de Datos.

## Principales Hallazgos

- Las ventas muestran una tendencia creciente durante el período analizado.
- Junio registra el mayor volumen de ventas del semestre.
- La página web es el canal con mayor contribución a las ventas.
- Las reclamaciones aumentan junto con el volumen de ventas, aunque los datos no permiten establecer una relación causal.
- La información disponible permite realizar análisis descriptivos y formular recomendaciones preliminares para la gerencia.
